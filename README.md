# 🛠️ Dev Productivity Suite

A modern, all-in-one developer toolbox that combines essential utilities for API testing, code formatting, data transformation, and more. Built with React and designed for developers who value efficiency.

## ✨ Features

### 🌐 API Tester
- Send HTTP requests (GET, POST, PUT, DELETE, PATCH)
- Dynamic header management (add/remove key-value pairs)
- JSON request body with real-time validation
- Formatted response display with syntax highlighting
- Comprehensive error handling and status code display

### 📝 JSON Tools
- **Format**: Pretty-print JSON with proper indentation
- **Validate**: Real-time JSON syntax validation
- **Minify**: Remove whitespace for compact output
- Instant error detection with helpful messages

### 🔍 Regex Tester
- Test regular expressions against sample text
- Support for multiple flags (global, case-insensitive, multiline)
- Live match highlighting with count display
- Extract all matches with index positions

### 🎨 Code Formatter
- Multi-language support (JavaScript, JSON, HTML, CSS)
- Powered by Prettier for consistent formatting
- Language auto-detection
- One-click beautification

### 🔐 UUID & Hash Generator
- Generate UUID v4 (random unique identifiers)
- SHA-1 and SHA-256 cryptographic hashing
- Base64 encoding and decoding
- Instant generation with copy-to-clipboard

## 🛠️ Tech Stack

**Frontend:**
- React 19.1.1 - UI framework
- Tailwind CSS 4.1.13 - Styling
- React Router DOM - Client-side routing
- Vite - Build tool and dev server

**Key Libraries:**
- Axios - HTTP client for API requests
- Prettier - Code formatting engine
- UUID - Unique identifier generation
- Web Crypto API - Secure hashing
